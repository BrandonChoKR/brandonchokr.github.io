# 버퍼 오버플로우(Buffer Overflow)
## 취약점 개요
버퍼 오버플로(Buffer Overflow)는 프로그램이 할당된 메모리 버퍼의 용량을 초과하는 데이터를 입력받아 인접 메모리 영역을 덮어쓰는 보안 취약점입니다. 이는 스택(Stack) 또는 힙(Heap) 영역에서 발생할 수 있으며, 공격자는 이를 악용해 프로그램 제어권을 탈취하거나 악성 코드를 실행할 수 있습니다.

#### 점검내용
사용자가 입력한 파라미터 값의 문자열 길이 제한 확인

#### 점검목적
웹 사이트에서 사용자가 입력한 파라미터 값의 문자열 길이 제한 여부를 점검하여 비정상적 오류 발생을 차단하기 위함

#### 보안위협
웹 사이트에서 사용자가 입력한 파라미터 값의 문자열 길이를 제한하지 않는 경우 개발 시에 할당된 저장 공간보다 더 큰 값의 입력이 가능하고 이로 인한 오류 발생 시 의도되지 않은 정보 노출, 프로그램에 대한 비인가 접근 및 사용 등이 발생할 수 있음
